# Game Design Portfolio

A consolidated collection of game development projects including board games, quiz games, and strategy games.

## Structure

### Board Games
- **malefiz/** - Malefiz board game implementation
- **stockticker/** - Stock Ticker (1937) board game desktop implementation

### Game of Sheep
Multiple implementations of the Game of Sheep:
- **original/** - Original implementation
- **typescript/** - TypeScript version
- **svelte/** - Svelte framework version  
- **alternative/** - Alternative implementation

### Quiz Games
- **croquet-quiz/** - Croquet knowledge quiz
- **llm-croquet-quiz/** - LLM-powered croquet quiz
- **critical-theory/** - Critical theory quiz
- **movie-quiz/** - Movie trivia quiz

## Technologies
Python, TypeScript, JavaScript, Svelte, Tkinter, and various web frameworks.
