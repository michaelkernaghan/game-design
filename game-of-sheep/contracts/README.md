# Smart Contracts

FA2 NFT smart contracts for the Game of Sheep.

These contracts implement the tokenomics for the sheep farming game:
- FA2 NFT standard for sheep tokens
- Token management and minting
- Admin controls
- Inspector mechanisms

## Files
- **fa2_*.mligo** - FA2 token standard implementation
- **token_*.mligo** - Token management contracts  
- **mint_tokens.mligo** - Minting functionality
- **simple_admin*.mligo** - Administrative contracts
- **inspector.mligo** - Contract inspection tools

See white_paper.md for full game mechanics.
